# Sincronización del data

- Cambiar a `users/alana.olivieri/venvs`
- Activar el env ejecutando:
```bash
.\Scripts\Activate.ps1
```
- Cambiar a `users/alana.olivieri/scripts_sync`
- Ejecutar el archivo de sincronización:
```bash
python sync_p2p_excel.py
```
